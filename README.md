# ShopX 2026 — Buildathon Landing Page

Standalone landing page for the ShopX 2026 Buildathon (afternoon build sprint).

- `index.html` — the page (static, no build step)
- Matches the dark/light band system + gradient-card style from the ShopX 2026 Figma design

## Deploy

Static site — deploy as-is on Vercel (no framework, output = root) or any static host.
